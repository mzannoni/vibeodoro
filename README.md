# VibeOdoro

This application started as a deliberate exercise of vibe coding.  
The goal is to create a TUI (terminal user interface) that implements a Pomodoro time-tracking technique tool.

Notable things done manually *the old way*:  
 * This README
 * The logo: made entirely by human hands and brain with Inkscape
 * License addition (text copy-pasted from the GNU website)
 * User experience tests, obviously: this little app is used and tested directly by a human

The name "VibeOdoro" itself comes from merging "pomodoro" with the concept of "vibe coding".
